# 神経衰弱の画像

このフォルダに置いた画像が、神経衰弱（`/memory`）のカードの絵柄になります。

- 画像 1 枚が 1 ペア（カード 2 枚）になります。2 枚以上置くと遊べるようになります
- 対応形式: JPG、PNG、WebP、AVIF
- 正方形に切り抜いて表示します。被写体は中央に寄せてください
- 6〜10 枚程度がおすすめです（カードは 12〜20 枚）
- ファイル名は読み上げ用の説明として使います。`01-takahashi.jpg` のように内容が分かる名前にしてください

画像を追加して GitHub へ push（マージ）すると、デプロイ後にサイトへ反映されます。
