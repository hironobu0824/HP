# 漫才コント「学び直しの大人だけの大学」ネタ帳

## コンセプト

- 大人の学び直しで大学に入る人が増えている
- 齊藤さんも大学に入りたいが、若い子ばかりの中に行くのは気まずい
- → 高橋：**「それなら、学び直しの大人だけが集まる大学があったらええやん」**
- → 高橋：「俺が大学の感じ味わわせたるわ」でコントに入る

笑いのもと：**大学のあるある** × **社会人・中年のクセ**。
「大学っぽいこと」をしているのに、中身が全部「会社」や「おじさん・おばさん」になってしまうズレ。

---

## 登場人物・役割

### 齊藤さん（ツッコミ）

- **高卒**。高校を出てすぐ働いてきた社会人
- 大学に行ってみたい気持ちがずっとある
- でも若い子ばかりの中に入るのは気まずくて、踏み出せない
- コント中は**齊藤さん本人のまま**、大人だけ大学の新入生として過ごす
- 大学を経験していないので、大学のイメージはドラマや漫画、人から聞いた話くらい
  - 「大学ってこういうもんなんや……」と一瞬信じかけてしまう
  - 憧れていた大学像（キャンパスライフ、サークル、学園祭）を楽しみにしている
- 大人だけ大学では、気になる女の子（ユキ）ができて**大学生みたいな恋愛**をし、振り回される
- ツッコミの軸は**社会人の感覚**
  - **「大人すぎるって！」**（大学生っぽい流れから急に大人が出たとき）
  - 「それ会社やん！」「それ毎日職場でやってるわ！」
  - 「俺が味わいたかったのはそれちゃうねん！」（憧れとのギャップ）

### 高橋（ボケ）

- **大卒**。大学の感じを知っている
- 大人だけの大学を提案して、齊藤さんに「味わわせてあげる」と言い出す
- コント中は**齊藤さん以外の登場人物を全部やる**
  - 学長、サークルの先輩、同級生、教授、バイト先の店長、学園祭の実行委員、面接官、卒業式の来賓 など
  - **ヒロインのユキ**、ユキのまわりの男たち（実は息子たち）、ユキの友達
  - 演じる人物がみんな大人なので、どの役も社会人・中年のクセが出てしまう
- 大学を知っているぶん、本物っぽいディテールを入れてくる
  - そのディテールに大人っぽさが混ざっていって、だんだん会社になる
- 自分の大学時代の思い出がたまに漏れる（「俺の頃はな〜」）

### この設定で生きるポイント

- 齊藤さんは大学を知らないので、高橋が「大学ってこういうもんやで」と言うと**一度は信じてしまう** → 社会人の感覚で「いや、これ会社やろ！」と気づく、という二段階のツッコミが作れる
- 大学を経験できなかった齊藤さんの**憧れ**があるので、そこを裏切られるたびにツッコミに熱がこもる
- 高橋が一人で何役もやるので、役の切り替え自体も見せ場になる（学長→先輩→教授…と演じ分けがどんどん雑になる、役どうしが同じ人に見えてくる、など）

## トーンの方針：基本は大学生、要所で大人が出る

- 大人だけの大学でも、みんな**中身は大学生**
  - 新歓で盛り上がる、サークルに入る、恋をする
  - 将来に希望を持っている。「まだ何者にもなれてない」「自分はこんなもんじゃない」と思っている
  - 斜に構えたり、背伸びしたり、夢を語ったりする
- その中で、**要所要所でだけ大人が漏れ出る**
- 齊藤さんのツッコミ：**「大人すぎるって！」**
- ずっと会社っぽいのではなく、ちゃんと青春していて、急に大人になるから落差で笑える

### 「大人すぎるって」ボケの例

| 大学生っぽいフリ | 漏れ出る大人 |
|---|---|
| 先輩「今夜は朝まで飲むぞー！」 | 21時になると「明日、人間ドックやから」で全員帰る |
| 先輩「一気！一気！」 | コップの中身がウコン |
| 同級生「俺、でっかいことしたいねん。まだ何者にもなれてへん」 | 「まずは住宅ローンを完済したい」 |
| 同級生「俺はこんなもんで終わる男ちゃう」 | 「係長のまま定年迎えてたまるか」 |
| 「将来の夢？世界中を旅したいな」 | 「年金もらえるようになったら」 |
| サークルの先輩「この夏、合宿で海行こうや！」 | 「日焼けはシミになるから日傘必須な」 |
| 新歓で「LINE交換しよ」 | QRを出すのに老眼鏡を探して3分かかる |
| 友達「昨日オールしたわ〜」 | 「夜中に3回トイレで起きただけ」 |
| 「金ないわ〜、今月ピンチ」 | 「ボーナスまでもたへん」「株が下がった」 |
| 恋バナ「好きなタイプは？」 | 「健康診断で引っかからん人」 |
| 自分探し「本当の自分って何やろな」 | 「人間ドックの結果見たらわかるで」 |

## 人生の冬休み

- 大学はよく「人生の夏休み」と言われる
- 大人だけの大学のキャッチコピーは **「人生の冬休み」**
  - 学長（高橋）「本学は、皆さんにとっての人生の冬休みです」
  - 齊藤さん「冬なん！？ 夏休みちゃうの！？」
  - 高橋「みんなもう夏は過ぎてるやろ」
- 冬休みだから、授業もイベントも冬休みっぽい
- 齊藤さんのツッコミ：**「めっちゃ冬休みやん！」**

### 冬休みネタの例

- **書き初めの授業が必修**（落とすと卒業できない）
- 宿題が「冬休みの友」と「絵日記」
- 講義室にこたつ。みかんが配られる
- 学食のメニューが雑煮とおせちだけ
  - 「餅は小さく切って食べてください」の張り紙（喉に詰まるので）→ 大人すぎるって
- 新歓が「新年会」、学園祭が「餅つき大会」
- 先輩からお年玉がもらえる → 先輩のほうが年下なので気まずい
- 年賀状のやり取りが必修
- 箱根駅伝を全員で見る授業
- 冬休みは終わるもの → 卒業＝冬休みの終わり＝現実に戻る（ラストへの伏線）

## 齊藤さんの恋愛ストーリー

### 狙い

- 齊藤さんが**大学生みたいな恋愛**をして、恋に振り回される
- 観客にも齊藤さんの心の動きを追わせる（ときめき → 不安 → 後悔 → 決意 → 告白 → 崩壊）
- ラストでヒロインの正体がわかったとき、**「あのとき言ってたのはそういうことやったんや」**と序盤のセリフがつながるようにする

### ヒロイン：ユキ（仮名）

**正体（ラストで明かす）**
- **既婚。5人の息子の母**（夫＋息子5人で、家に男が6人）
- 子育てと家事に疲れて、「人生の冬休み」として大学に来た
- 学生気分を味わいたくて、既婚であることを言わずにいた
- 齊藤さんのことは本当に好きだった。ただし「冬休みのあいだだけ」の好き
- 悪気がなさそうなところが嫌な感じ
  - 思わせぶりで、齊藤さんに荷物を持たせたり、ノートを写させてもらったり、奢らせたりしてきた
  - バレても謝らない。「言うてへんかったっけ？」「いい大人が何してんの」

**学生のときの見え方**
- 入学式で一人ぼっち。ちょっと影があって、守ってあげたくなる
- 明るくてノリがいい。新歓ではしゃぐ
- 齊藤さんにだけ弱いところを見せる（ように見える）

### 恋愛パートの流れ

1. **出会い（入学式）**
   - 一人で手袋をしたまま座っているユキに、齊藤さんが勇気を出して話しかける
   - 「ユキって呼んで」で一気に心をつかまれる
   - 齊藤さん「大学来てよかった……！」
2. **急接近（新歓）**
   - 一緒に新歓コンパ。取り分け、呼び間違い、「タイプやわ」
   - 齊藤さん、完全に浮かれる。「俺、大学生してる……！」
   - でも5時半に帰ってしまう。「門限あるねん」
3. **ちょっと切ない（授業・書き初め）**
   - 書き初めで隣の席。ユキは「自由」、齊藤さんは「青春」
   - 「冬休みが終わったら、戻らなあかん」「言えてないことがある」
   - 齊藤さん、意味がわからないまま胸がざわつく
4. **疎遠（バイト・就活の時期）**
   - ユキが大学に来なくなる。LINEも既読がつかない
   - 齊藤さん、バイトにも就活にも身が入らない
   - 齊藤さん「俺、何かしたんかな……」
5. **ユキの本当の気持ちを知る**
   - ユキの友達（高橋）から「あの子、齊藤さんのこと好きやってんで」
   - 証拠として、ユキの冬休みの絵日記を見せてもらう（絵日記の宿題を使う）
     - 「きょうも齊藤くんとしゃべった。たのしかった」
     - 「家の男たちとちがって、齊藤くんはやさしい」← これも伏線
   - 齊藤さん「なんで俺、あのとき追いかけへんかったんや……！」
6. **会いに行く（卒業式）**
   - 卒業式の日、ユキに会いに行く
   - ユキのまわりに男がいる。しかも一人じゃない
   - 齊藤さん「そんな男やめて、俺にしなよ！」と男たちに割って入る
   - 高橋が男たちを次々に演じる（長男 → 次男 → 三男 → 四男 → 五男）
     - 長男「母さん、この人誰？」
     - ……五男はベビーカー
   - 齊藤さん「……母さん！？」
   - 入学式あるある「親が来てる」の回収：**来てるのは夫と5人の息子**
7. **崩壊**
   - ユキ「言うてへんかったっけ？ 5人おるって」
   - 齊藤さん「兄弟やと思ってたわ！」
   - ユキ「齊藤くん、いい大人が何してんの」
   - 齊藤さん「お前が言うな！」
   - ユキ「冬休み、楽しかったわ。ほな」

## 1. 大学あるある（シーン別）

### 入学式

- スーツが似合ってない（着せられてる感）
- 親が来ている。親のほうが張り切ってる
- 学長の話が長い。誰も聞いてない
- 武道館などやたら大きい会場
- 看板の前で写真を撮るための行列
- 地元の友達と同じスーツの色かぶり
- 隣の席の人に話しかけるかどうか迷う
- 「どこ出身？」「学部どこ？」の質問攻め
- 式のあとサークルの勧誘に囲まれる
- 校歌を誰も知らない（歌詞カードを見ながら口パク）

### 新歓

- ビラを大量にもらう。両手がビラでいっぱい
- 「新歓の時期だけ」ご飯がタダ
- 先輩がやたら優しい（入ったら態度が変わる）
- テニサーが多すぎる。テニスをしないテニサー
- 「ゆるい感じだから！」と言われるが全然ゆるくない
- 新歓コンパで自己紹介→名前と学部と出身と「趣味は〜」
- コール・一気（※今はアウト）
- LINEグループに次々入れられる
- 結局どこにも入らない人もいる
- 1年の時の新歓で人間関係がほぼ決まる

### 授業

- 履修登録が戦争。楽単（楽に単位が取れる授業）の情報戦
- 1限に出られない
- 後ろの席から埋まる。前の席は真面目な人だけ
- 代返（今は出席がスマホ・カードなので難しい）
- 教授の話が脱線する。脱線のほうが面白い
- テスト前だけノートのコピーが出回る
- 「出席取らない授業」は最初だけ人が多い
- 寝てる人、スマホいじってる人、内職してる人
- レポートの文字数を増やすための水増し
- 教授が「この授業は単位が厳しい」と最初に脅す
- 休講情報で大喜び
- グループワークでフリーライダーが出る
- 「過去問」をどの先輩から手に入れるか

### バイト

- 居酒屋・コンビニ・塾講師・カフェが定番
- シフトを入れすぎて授業に出られない
- 店長に頼まれると断れない
- まかないが目当て
- 給料日の後だけ羽振りがいい
- バイト先の人間関係のほうが濃い（サークル化）
- 「大学何年？」と社員に聞かれる
- 年下の高校生バイトに仕事を教わる
- バイトリーダーになって責任感がつく
- 時給10円アップで本気で喜ぶ

### 学園祭

- 模擬店で焼きそば・たこ焼き・チョコバナナ
- 原価計算がめちゃくちゃで赤字
- 準備期間のほうが楽しい
- 実行委員がずっと忙しそう
- ミスコン・ミスターコン
- お笑いライブにちょっと売れた芸人が来る
- 有名人ゲスト・アーティストライブ
- 打ち上げで泣く人がいる
- 「来年もやろうな」が恒例
- 他大学の学園祭にも行く

### 就活

- みんな一斉に黒髪・リクルートスーツ
- ES（エントリーシート）の「ガクチカ」（学生時代に力を入れたこと）が書けない
- 「サークルで副代表をしてました」がやたら多い
- 自己分析で自分がわからなくなる
- 面接で「御社が第一志望です」と全社に言う
- 「あなたを動物に例えると？」
- グループディスカッションで仕切りたがる人
- お祈りメール（不採用通知）
- 内定が出た人と出てない人の空気
- OB・OG訪問
- インターンという名の選考

### 卒業式

- 袴（女子）・スーツ（男子）。袴の着付けで朝が早い
- 卒業できるかギリギリだった人がいる
- 単位が足りなくて卒業式に出られない人
- 卒業アルバム・寄せ書き
- 「またすぐ会おうな」→ 会わない
- 謝恩会・卒業旅行
- 4年間あっという間だった、と言う
- 学長の話がまた長い
- 胴上げ・サークルの後輩から花束
- 社会人になる不安と寂しさ

## 2. 大人っぽい要素（社会人・中年あるある）

### 社会人のクセ・口ぐせ

- 「お疲れ様です」が挨拶
- 「確認して折り返します」「持ち帰って検討します」
- 「念のため」「一応」「認識合ってますか？」
- 「いったん」「ざっくり」「よしなに」
- 「すみません、ちょっと3分だけいいですか？」→ 30分
- 「お世話になっております」をメール以外でも言う
- 「前向きに検討します」（＝やらない）
- 「そこはマストで」「ASAPで」「エビデンスは？」
- カタカナビジネス用語（アジェンダ、コンセンサス、リスケ、アサイン、バッファ）
- 名刺交換の作法。名刺を出す手が速い
- 上座・下座を気にする
- エレベーターのボタンを押す係を自然にやる

### 会社・組織っぽさ

- 何でも会議。会議のための会議
- 稟議・ハンコ・決裁
- 報連相（報告・連絡・相談）
- 根回し
- 議事録を取る人
- 前例がないとできない
- 年功序列・肩書き（部長・課長）
- 飲み会での乾杯の挨拶・締めの挨拶（一本締め）
- 忘年会・新年会の幹事
- 有給が取りづらい
- 定時で帰りにくい
- 社内政治・派閥
- Excelで何でも管理
- 「それって予算どこから出るの？」

### 中年の体・健康

- 腰が痛い、膝が痛い、肩が上がらない（四十肩・五十肩）
- 老眼。スマホを遠ざけて見る
- 健康診断の数値（尿酸値・コレステロール・血圧）
- 二日酔いが2日続く
- 徹夜ができない
- 階段を避けてエスカレーター
- 立ち上がるときに「よいしょ」
- 寝ても疲れが取れない

## 4. 構成メモ（たたき台）

1. **フリ**（齊藤さん）：最近、大人の学び直しで大学に入る人がいるらしい。実は俺も大学行ってみたいねん。高卒やから
2. **悩み**（齊藤さん）：でも若い子ばっかりの中に一人だけおっさんがおったら気まずいやろ
3. **提案**（高橋）：ほな、学び直しの大人だけが集まる大学があったらええやん。俺、大卒やから大学の感じわかるし、味わわせたるわ。俺がほかの人全部やるから、齊藤さんは新入生な
4. **コント本編**：入学式 → 新歓 → 授業 → バイト・就活 → 卒業式 と時系列で進める
   - 高橋は場面ごとに学長、先輩、教授、ユキ、店長、面接官…と役を替えていく
   - 基本はみんな大学生っぽい。要所でだけ大人が漏れて、齊藤さん「大人すぎるって！」
   - 「人生の冬休み」の設定で、冬休みネタを挟む（書き初め必修 →「めっちゃ冬休みやん！」）
   - 縦軸として、齊藤さんとユキの恋愛が進む

| 場面 | 大学・冬休みネタ | 恋愛ライン |
|---|---|---|
| 入学式 | 学長「人生の冬休みへようこそ」、名刺交換 | ユキと出会う。手袋、「ユキって呼んで」「男が6人おる」 |
| 新歓 | 朝まで飲むぞ → 21時解散、ウコン一気 | 取り分け、「タクヤ」呼び間違い、「タイプやわ」、5時半の門限 |
| 授業 | 書き初めが必修、こたつ、雑煮の学食 | 隣で書き初め。「自由」「戻らなあかん」「言えてないことある」 |
| バイト・就活 | 夢を語るが住宅ローン、面接官が年下 | ユキが来なくなる。齊藤さんは上の空 |
| （つなぎ） | 冬休みの絵日記の宿題 | ユキの友達から「好きやってんで」、絵日記を見る |
| 卒業式 | 冬休みの終わり＝現実に戻る | 告白 → 男たちは息子5人 → 崩壊 |

5. **オチ案**
   - ユキ「いい大人が何してんの」→ 齊藤さん「お前が言うな！」→ 伏線回収の連打 →「大人すぎるって！」
   - 卒業式で書き初めをもう一回。齊藤さんが「青春」の上から「**大人**」と書き直す
   - ユキ「冬休み、楽しかったわ」→ 齊藤さん「俺の冬休み、宿題しか残ってへん！」
   - 齊藤さん「こんなんやったら、若い子の中に入るほうがマシやわ。普通の大学行くわ」→ 高橋「ほな、背中押せたな」（悩みが解決する逆転）
   - 高橋「俺も大学の頃、こんな恋したけどな」→ 齊藤さん「お前の大学どうなってんねん！」
