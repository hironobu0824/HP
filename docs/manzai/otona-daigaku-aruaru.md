# 漫才コント「学び直しの大人だけの大学」ネタ帳

## コンセプト

- 大人の学び直しで大学に入る人が増えている
- 齊藤さんも大学に入りたいが、若い子ばかりの中に行くのは気まずい
- → 高橋：**「それなら、学び直しの大人だけが集まる大学があったらええやん」**
- → 高橋：「俺が大学の感じ味わわせたるわ」でコントに入る

笑いのもと：**大学のあるある** × **社会人・中年のクセ**。
「大学っぽいこと」をしているのに、中身が全部「会社」や「おじさん・おばさん」になってしまうズレ。

---

## 登場人物・役割

### 齊藤さん（ツッコミ）

- **高卒**。高校を出てすぐ働いてきた社会人
- 大学に行ってみたい気持ちがずっとある
- でも若い子ばかりの中に入るのは気まずくて、踏み出せない
- コント中は**齊藤さん本人のまま**、大人だけ大学の新入生として過ごす
- 大学を経験していないので、大学のイメージはドラマや漫画、人から聞いた話くらい
  - 「大学ってこういうもんなんや……」と一瞬信じかけてしまう
  - 憧れていた大学像（キャンパスライフ、サークル、学園祭）を楽しみにしている
- ツッコミの軸は**社会人の感覚**
  - 「それ会社やん！」「それ毎日職場でやってるわ！」
  - 「俺が味わいたかったのはそれちゃうねん！」（憧れとのギャップ）

### 高橋（ボケ）

- **大卒**。大学の感じを知っている
- 大人だけの大学を提案して、齊藤さんに「味わわせてあげる」と言い出す
- コント中は**齊藤さん以外の登場人物を全部やる**
  - 学長、サークルの先輩、同級生、教授、バイト先の店長、学園祭の実行委員、面接官、卒業式の来賓 など
  - 演じる人物がみんな大人なので、どの役も社会人・中年のクセが出てしまう
- 大学を知っているぶん、本物っぽいディテールを入れてくる
  - そのディテールに大人っぽさが混ざっていって、だんだん会社になる
- 自分の大学時代の思い出がたまに漏れる（「俺の頃はな〜」）

### この設定で生きるポイント

- 齊藤さんは大学を知らないので、高橋が「大学ってこういうもんやで」と言うと**一度は信じてしまう** → 社会人の感覚で「いや、これ会社やろ！」と気づく、という二段階のツッコミが作れる
- 大学を経験できなかった齊藤さんの**憧れ**があるので、そこを裏切られるたびにツッコミに熱がこもる
- 高橋が一人で何役もやるので、役の切り替え自体も見せ場になる（学長→先輩→教授…と演じ分けがどんどん雑になる、役どうしが同じ人に見えてくる、など）

## 1. 大学あるある（シーン別）

### 入学式

- スーツが似合ってない（着せられてる感）
- 親が来ている。親のほうが張り切ってる
- 学長の話が長い。誰も聞いてない
- 武道館などやたら大きい会場
- 看板の前で写真を撮るための行列
- 地元の友達と同じスーツの色かぶり
- 隣の席の人に話しかけるかどうか迷う
- 「どこ出身？」「学部どこ？」の質問攻め
- 式のあとサークルの勧誘に囲まれる
- 校歌を誰も知らない（歌詞カードを見ながら口パク）

### 新歓

- ビラを大量にもらう。両手がビラでいっぱい
- 「新歓の時期だけ」ご飯がタダ
- 先輩がやたら優しい（入ったら態度が変わる）
- テニサーが多すぎる。テニスをしないテニサー
- 「ゆるい感じだから！」と言われるが全然ゆるくない
- 新歓コンパで自己紹介→名前と学部と出身と「趣味は〜」
- コール・一気（※今はアウト）
- LINEグループに次々入れられる
- 結局どこにも入らない人もいる
- 1年の時の新歓で人間関係がほぼ決まる

### 授業

- 履修登録が戦争。楽単（楽に単位が取れる授業）の情報戦
- 1限に出られない
- 後ろの席から埋まる。前の席は真面目な人だけ
- 代返（今は出席がスマホ・カードなので難しい）
- 教授の話が脱線する。脱線のほうが面白い
- テスト前だけノートのコピーが出回る
- 「出席取らない授業」は最初だけ人が多い
- 寝てる人、スマホいじってる人、内職してる人
- レポートの文字数を増やすための水増し
- 教授が「この授業は単位が厳しい」と最初に脅す
- 休講情報で大喜び
- グループワークでフリーライダーが出る
- 「過去問」をどの先輩から手に入れるか

### バイト

- 居酒屋・コンビニ・塾講師・カフェが定番
- シフトを入れすぎて授業に出られない
- 店長に頼まれると断れない
- まかないが目当て
- 給料日の後だけ羽振りがいい
- バイト先の人間関係のほうが濃い（サークル化）
- 「大学何年？」と社員に聞かれる
- 年下の高校生バイトに仕事を教わる
- バイトリーダーになって責任感がつく
- 時給10円アップで本気で喜ぶ

### 学園祭

- 模擬店で焼きそば・たこ焼き・チョコバナナ
- 原価計算がめちゃくちゃで赤字
- 準備期間のほうが楽しい
- 実行委員がずっと忙しそう
- ミスコン・ミスターコン
- お笑いライブにちょっと売れた芸人が来る
- 有名人ゲスト・アーティストライブ
- 打ち上げで泣く人がいる
- 「来年もやろうな」が恒例
- 他大学の学園祭にも行く

### 就活

- みんな一斉に黒髪・リクルートスーツ
- ES（エントリーシート）の「ガクチカ」（学生時代に力を入れたこと）が書けない
- 「サークルで副代表をしてました」がやたら多い
- 自己分析で自分がわからなくなる
- 面接で「御社が第一志望です」と全社に言う
- 「あなたを動物に例えると？」
- グループディスカッションで仕切りたがる人
- お祈りメール（不採用通知）
- 内定が出た人と出てない人の空気
- OB・OG訪問
- インターンという名の選考

### 卒業式

- 袴（女子）・スーツ（男子）。袴の着付けで朝が早い
- 卒業できるかギリギリだった人がいる
- 単位が足りなくて卒業式に出られない人
- 卒業アルバム・寄せ書き
- 「またすぐ会おうな」→ 会わない
- 謝恩会・卒業旅行
- 4年間あっという間だった、と言う
- 学長の話がまた長い
- 胴上げ・サークルの後輩から花束
- 社会人になる不安と寂しさ

## 2. 大人っぽい要素（社会人・中年あるある）

### 社会人のクセ・口ぐせ

- 「お疲れ様です」が挨拶
- 「確認して折り返します」「持ち帰って検討します」
- 「念のため」「一応」「認識合ってますか？」
- 「いったん」「ざっくり」「よしなに」
- 「すみません、ちょっと3分だけいいですか？」→ 30分
- 「お世話になっております」をメール以外でも言う
- 「前向きに検討します」（＝やらない）
- 「そこはマストで」「ASAPで」「エビデンスは？」
- カタカナビジネス用語（アジェンダ、コンセンサス、リスケ、アサイン、バッファ）
- 名刺交換の作法。名刺を出す手が速い
- 上座・下座を気にする
- エレベーターのボタンを押す係を自然にやる

### 会社・組織っぽさ

- 何でも会議。会議のための会議
- 稟議・ハンコ・決裁
- 報連相（報告・連絡・相談）
- 根回し
- 議事録を取る人
- 前例がないとできない
- 年功序列・肩書き（部長・課長）
- 飲み会での乾杯の挨拶・締めの挨拶（一本締め）
- 忘年会・新年会の幹事
- 有給が取りづらい
- 定時で帰りにくい
- 社内政治・派閥
- Excelで何でも管理
- 「それって予算どこから出るの？」

### 中年の体・健康

- 腰が痛い、膝が痛い、肩が上がらない（四十肩・五十肩）
- 老眼。スマホを遠ざけて見る
- 健康診断の数値（尿酸値・コレステロール・血圧）
- 二日酔いが2日続く
- 徹夜ができない
- 階段を避けてエスカレーター
- 立ち上がるときに「よいしょ」
- 寝ても疲れが取れない
- サプリ・青汁・プロテインの話
- 夜10時には眠い
- 筋肉痛が2日後に来る

### 家庭・生活

- 子どもの送り迎え・PTA
- 住宅ローン
- 子どもの塾代・学費
- 親の介護
- 妻（夫）に小遣い制
- 休日は家族サービス
- 子どものほうが大学の先輩（親子で同じ大学問題）
- 冷蔵庫のマグネットに予定表
- 家に帰ると居場所がない

### 中年の感覚・文化

- 昔話が長い（「俺らの頃は〜」）
- 武勇伝
- 若者言葉がわからない・無理して使う
- LINEの文章が長い・絵文字が古い・句読点が多い
- 「最近の若いもんは」
- ゴルフ・釣り・キャンプ・サウナ
- 昭和・平成の流行の話
- 話の最初に「結論から言うと」と言うが結論が出ない
- 自己紹介で前職や肩書きを言いたがる
- マウントの取り合い（年収・役職・会社の規模）
- 割り勘で細かい
- 「領収書ください」
- 飲み会の二次会でスナック・カラオケ（十八番が昭和歌謡）

### お金

- 学費を経費で落とそうとする
- 会社の補助制度・給付金・リスキリング支援
- 「投資対効果は？」「ROIは？」
- 退職金・年金の話
- NISA・iDeCo

## 4. 構成メモ（たたき台）

1. **フリ**（齊藤さん）：最近、大人の学び直しで大学に入る人がいるらしい。実は俺も大学行ってみたいねん。高卒やから
2. **悩み**（齊藤さん）：でも若い子ばっかりの中に一人だけおっさんがおったら気まずいやろ
3. **提案**（高橋）：ほな、学び直しの大人だけが集まる大学があったらええやん。俺、大卒やから大学の感じわかるし、味わわせたるわ。俺がほかの人全部やるから、齊藤さんは新入生な
4. **コント本編**：入学式 → 新歓 → 授業 → バイト → 学園祭 → 就活 → 卒業式 と時系列で進める
   - 高橋は場面ごとに学長、先輩、教授、店長、面接官…と役を替えていく
   - 齊藤さんは毎回、憧れの大学を期待してワクワクして入る → 裏切られてツッコむ
   - 序盤は「わかる」系の小さなズレ（名刺交換、腰が痛い）
     - 齊藤さんが「大学ってこういうもんなん？」と一瞬信じかける
   - 中盤で会社っぽさが加速（稟議、会議、議事録）
     - 齊藤さん「これ毎日職場でやってるやつや！」
   - 終盤で大学の要素が完全になくなる（もはや会社）
     - 高橋の役の演じ分けも雑になって、全員同じ「部長」みたいになる
5. **オチ案**
   - 齊藤さん「これ、ただの会社やないか！俺、高校出てからずっとこれ味わってんねん！」
   - 卒業後の進路が「元の会社に戻る」→ 齊藤さん「学び直す前と何も変わってへん」
   - 卒業式で「また学び直しに来ます」→ 永遠に卒業できない
   - 齊藤さん「こんなんやったら、若い子の中に入るほうがマシやわ。普通の大学行くわ」→ 高橋「ほな、背中押せたな」（悩みが解決する逆転）
   - 高橋「俺も大学の頃こんな感じやったけどな」→ 齊藤さん「お前の大学どうなってんねん！」
