# 漫才コント「学び直しの大人だけの大学」ネタ帳

## コンセプト

- 大人の学び直しで大学に入る人が増えている
- でも、18〜22歳の中に一人だけ大人がいると馴染みづらい
- → **「それなら、学び直しの大人だけが集まる大学があったらいいんじゃない？」**
- → 「その感じをやってみる」でコントに入る

ボケ：大人だけ大学の学生（または学長・先輩など）
ツッコミ：普通の大学の感覚で見ている人

笑いのもと：**大学のあるある** × **社会人・中年のクセ**。
「大学っぽいこと」をしているのに、中身が全部「会社」や「おじさん・おばさん」になってしまうズレ。

## 1. 大学あるある（シーン別）

### 入学式

- スーツが似合ってない（着せられてる感）
- 親が来ている。親のほうが張り切ってる
- 学長の話が長い。誰も聞いてない
- 武道館などやたら大きい会場
- 看板の前で写真を撮るための行列
- 地元の友達と同じスーツの色かぶり
- 隣の席の人に話しかけるかどうか迷う
- 「どこ出身？」「学部どこ？」の質問攻め
- 式のあとサークルの勧誘に囲まれる
- 校歌を誰も知らない（歌詞カードを見ながら口パク）

### 新歓

- ビラを大量にもらう。両手がビラでいっぱい
- 「新歓の時期だけ」ご飯がタダ
- 先輩がやたら優しい（入ったら態度が変わる）
- テニサーが多すぎる。テニスをしないテニサー
- 「ゆるい感じだから！」と言われるが全然ゆるくない
- 新歓コンパで自己紹介→名前と学部と出身と「趣味は〜」
- コール・一気（※今はアウト）
- LINEグループに次々入れられる
- 結局どこにも入らない人もいる
- 1年の時の新歓で人間関係がほぼ決まる

### 授業

- 履修登録が戦争。楽単（楽に単位が取れる授業）の情報戦
- 1限に出られない
- 後ろの席から埋まる。前の席は真面目な人だけ
- 代返（今は出席がスマホ・カードなので難しい）
- 教授の話が脱線する。脱線のほうが面白い
- テスト前だけノートのコピーが出回る
- 「出席取らない授業」は最初だけ人が多い
- 寝てる人、スマホいじってる人、内職してる人
- レポートの文字数を増やすための水増し
- 教授が「この授業は単位が厳しい」と最初に脅す
- 休講情報で大喜び
- グループワークでフリーライダーが出る
- 「過去問」をどの先輩から手に入れるか

### バイト

- 居酒屋・コンビニ・塾講師・カフェが定番
- シフトを入れすぎて授業に出られない
- 店長に頼まれると断れない
- まかないが目当て
- 給料日の後だけ羽振りがいい
- バイト先の人間関係のほうが濃い（サークル化）
- 「大学何年？」と社員に聞かれる
- 年下の高校生バイトに仕事を教わる
- バイトリーダーになって責任感がつく
- 時給10円アップで本気で喜ぶ

### 学園祭

- 模擬店で焼きそば・たこ焼き・チョコバナナ
- 原価計算がめちゃくちゃで赤字
- 準備期間のほうが楽しい
- 実行委員がずっと忙しそう
- ミスコン・ミスターコン
- お笑いライブにちょっと売れた芸人が来る
- 有名人ゲスト・アーティストライブ
- 打ち上げで泣く人がいる
- 「来年もやろうな」が恒例
- 他大学の学園祭にも行く

### 就活

- みんな一斉に黒髪・リクルートスーツ
- ES（エントリーシート）の「ガクチカ」（学生時代に力を入れたこと）が書けない
- 「サークルで副代表をしてました」がやたら多い
- 自己分析で自分がわからなくなる
- 面接で「御社が第一志望です」と全社に言う
- 「あなたを動物に例えると？」
- グループディスカッションで仕切りたがる人
- お祈りメール（不採用通知）
- 内定が出た人と出てない人の空気
- OB・OG訪問
- インターンという名の選考

### 卒業式

- 袴（女子）・スーツ（男子）。袴の着付けで朝が早い
- 卒業できるかギリギリだった人がいる
- 単位が足りなくて卒業式に出られない人
- 卒業アルバム・寄せ書き
- 「またすぐ会おうな」→ 会わない
- 謝恩会・卒業旅行
- 4年間あっという間だった、と言う
- 学長の話がまた長い
- 胴上げ・サークルの後輩から花束
- 社会人になる不安と寂しさ

## 2. 大人っぽい要素（社会人・中年あるある）

### 社会人のクセ・口ぐせ

- 「お疲れ様です」が挨拶
- 「確認して折り返します」「持ち帰って検討します」
- 「念のため」「一応」「認識合ってますか？」
- 「いったん」「ざっくり」「よしなに」
- 「すみません、ちょっと3分だけいいですか？」→ 30分
- 「お世話になっております」をメール以外でも言う
- 「前向きに検討します」（＝やらない）
- 「そこはマストで」「ASAPで」「エビデンスは？」
- カタカナビジネス用語（アジェンダ、コンセンサス、リスケ、アサイン、バッファ）
- 名刺交換の作法。名刺を出す手が速い
- 上座・下座を気にする
- エレベーターのボタンを押す係を自然にやる

### 会社・組織っぽさ

- 何でも会議。会議のための会議
- 稟議・ハンコ・決裁
- 報連相（報告・連絡・相談）
- 根回し
- 議事録を取る人
- 前例がないとできない
- 年功序列・肩書き（部長・課長）
- 飲み会での乾杯の挨拶・締めの挨拶（一本締め）
- 忘年会・新年会の幹事
- 有給が取りづらい
- 定時で帰りにくい
- 社内政治・派閥
- Excelで何でも管理
- 「それって予算どこから出るの？」

### 中年の体・健康

- 腰が痛い、膝が痛い、肩が上がらない（四十肩・五十肩）
- 老眼。スマホを遠ざけて見る
- 健康診断の数値（尿酸値・コレステロール・血圧）
- 二日酔いが2日続く
- 徹夜ができない
- 階段を避けてエスカレーター
- 立ち上がるときに「よいしょ」
- 寝ても疲れが取れない
- サプリ・青汁・プロテインの話
- 夜10時には眠い
- 筋肉痛が2日後に来る

### 家庭・生活

- 子どもの送り迎え・PTA
- 住宅ローン
- 子どもの塾代・学費
- 親の介護
- 妻（夫）に小遣い制
- 休日は家族サービス
- 子どものほうが大学の先輩（親子で同じ大学問題）
- 冷蔵庫のマグネットに予定表
- 家に帰ると居場所がない

### 中年の感覚・文化

- 昔話が長い（「俺らの頃は〜」）
- 武勇伝
- 若者言葉がわからない・無理して使う
- LINEの文章が長い・絵文字が古い・句読点が多い
- 「最近の若いもんは」
- ゴルフ・釣り・キャンプ・サウナ
- 昭和・平成の流行の話
- 話の最初に「結論から言うと」と言うが結論が出ない
- 自己紹介で前職や肩書きを言いたがる
- マウントの取り合い（年収・役職・会社の規模）
- 割り勘で細かい
- 「領収書ください」
- 飲み会の二次会でスナック・カラオケ（十八番が昭和歌謡）

### お金

- 学費を経費で落とそうとする
- 会社の補助制度・給付金・リスキリング支援
- 「投資対効果は？」「ROIは？」
- 退職金・年金の話
- NISA・iDeCo

## 4. 構成メモ（たたき台）

1. **フリ**：最近、大人の学び直しで大学に入る人がいるらしい
2. **共感**：でも若い子の中に一人だけおじさんがいたら馴染めないよね
3. **提案**：だったら大人だけの大学を作ればいい → 「ちょっとやってみよう」
4. **コント本編**：入学式 → 新歓 → 授業 → 学園祭 → 就活 → 卒業式 と時系列で進める
   - 序盤は「わかる」系の小さなズレ（名刺交換、腰が痛い）
   - 中盤で会社っぽさが加速（稟議、会議、議事録）
   - 終盤で大学の要素が完全になくなる（もはや会社）
5. **オチ案**
   - 「これ、ただの会社やないか！」
   - 卒業後の進路が「元の会社に戻る」→「学び直す前と何も変わってへん」
   - 卒業式で「また学び直しに来ます」→ 永遠に卒業できない
   - 結局、大人だけの大学でも馴染めない（ツッコミ側が若者側に回る逆転）
